# Capstone Project Pekan Ristek 2026 - Cheers
Aplikasi pencatat mood sederhana yang dibuat dengan Flutter. Pengguna bisa mencatat perasaan harian, menambahkan catatan singkat, lalu melihat ringkasannya dalam seminggu. Pengguna diharuskan untuk login terlebih dahulu. 

## Cara Menjalankan
flutter pub get
flutter run

## Untuk test Hive
Untuk menjalankan di browser, pakai port yang tetap agar data tidak hilang saat dijalankan ulang.
flutter run -d edge --web-port=5000

## Untuk melihat logo aplikasi & mencobba di mobile
flutter build apk --release
Tampilannya sudah rapih untuk HP saya (Samsung A15)
